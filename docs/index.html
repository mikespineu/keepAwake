What it does

Presets, a custom time of up to 30 days, or Always. Chosen each time you turn it on.

Turns itself off when the battery drops below your limit, so a forgotten timer never drains your laptop.

Remaining time in the menu bar, a sound when the time is up, and a notification when keepAwake stops on its own.

Optionally keep the screen on too, and start keepAwake when you log in. Lock the screen from the menu and your Mac keeps working.

Use with AI agents

Connect

Open the keepAwake menu and click Connect: Claude Code or Cursor, then start a new agent session. It adds keepAwake's hooks and MCP server to that app's settings, and keeps a backup copy of each file it changes.

While the agent works

Every prompt and tool call keeps the Mac awake for the next 30 minutes. When the agent finishes, or crashes, the Mac can sleep again. You can also ask the agent to “keep my Mac awake for 3 hours”.

You're in charge

The menu lists every agent holding the Mac awake. Click × to end one, or Turn Off to end them all. The hooks never read your prompts.

Terminal, scripts and other MCP clients

The app is also a command-line tool. It talks to the running app and starts it if needed:

/Applications/keepAwake.app/Contents/MacOS/KeepAwake install claude-code
/Applications/keepAwake.app/Contents/MacOS/KeepAwake hold --id backup --minutes 60
open -g "keepawake://release?id=backup"

Other MCP clients can run KeepAwake mcp as a stdio server. All commands are in the README.

Install

  1. Download

    Click Download for Mac. The file keepAwake.zip lands in your Downloads folder.

  2. Unzip

    Double-click keepAwake.zip. macOS unpacks it into keepAwake.app next to it.

  3. Drag it to Applications

    Open a new Finder window, choose Applications in the sidebar, and drag keepAwake.app into it.

  4. Allow it in Privacy & Security (first launch only)

    keepAwake is from an independent developer and isn't notarized by Apple, so the first time you open it macOS blocks it. This is expected — you just have to give it permission once.

    a. Double-click keepAwake in Applications. You'll see “keepAwake” Not Opened. Click Done.

    b. Open Apple menu → System Settings → Privacy & Security.

    c. Scroll down to the Security section. You'll find this message — click Open Anyway:

    Security
    “keepAwake” was blocked to protect your Mac. Open Anyway

    d. Enter your password or use Touch ID.

    e. macOS asks one more time — click Open Anyway. keepAwake starts and the mug appears in the menu bar.

    No “Open Anyway” button? It only shows up for about an hour after macOS blocked the app. Double-click keepAwake again, click Done, and go back to Privacy & Security.
    You don't need to change “Allow applications from” or turn off any protection — the button above allows only keepAwake.

    You'll do this once per download, so again after installing an update. keepAwake is free and open source — you can read every line of the source code or build it yourself.

    Prefer Terminal?

    Instead of steps a–e, remove the download quarantine flag, then open the app normally:

    xattr -dr com.apple.quarantine /Applications/keepAwake.app

  5. Click the mug in the menu bar

    There's no window or Dock icon — keepAwake lives in the menu bar at the top right. Pick a duration and you're done. Allow notifications if you want to know when it stops on its own.

Update & uninstall

Update

Quit keepAwake from its menu, download the new version, and replace the app in Applications. See what changed in the changelog.

Uninstall

Quit keepAwake and move it from Applications to the Bin. Settings live in ~/Library/Preferences/com.michalkrecisz.keepAwake.plist. If you used Keep awake with lid closed, also run sudo rm -f /etc/sudoers.d/keepawake in Terminal. If you connected an AI agent, first run …/KeepAwake uninstall claude-code or uninstall cursor (see the README).

Build it yourself

Needs only the Xcode Command Line Tools. See the README.
