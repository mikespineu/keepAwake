# keepAwake v1.1.0 — tryb „zamknięta klapa” — plan implementacji

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Cel:** gdy keepAwake jest włączony i opcja „Keep awake with lid closed” jest zaznaczona, Mac nie zasypia po zamknięciu klapy (także bez zewnętrznego monitora).

**Architektura:** macOS nie pozwala zablokować uśpienia po zamknięciu klapy żadnym assertion IOKit. Jedyna droga to `pmset -a disablesleep 1`, które wymaga roota. Instalujemy więc jednorazowo (hasło admina przez `osascript … with administrator privileges`) plik `/etc/sudoers.d/keepawake`, który pozwala bieżącemu użytkownikowi uruchamiać bez hasła **wyłącznie** `pmset -a disablesleep 1` i `pmset -a disablesleep 0`. Aplikacja włącza override razem z keepAwake i wyłącza go przy każdym stopie. Odłączony proces-strażnik (`/bin/sh`) cofa override, jeśli aplikacja padnie.

**Tech stack:** Swift 6, SwiftUI `MenuBarExtra`, IOKit, `sudo`/`pmset`/`osascript`, Swift Testing.

**Spec:** decyzje z rozmowy z 2026-10-25 (zebrane niżej w „Decyzjach”); osobnego dokumentu specyfikacji brak.

## Decyzje

- Dystrybucja tylko jako ZIP z GitHub Releases / GitHub Pages. Wersja App Store na razie odpada, ale projekt Xcode i `APPSTORE.md` zostają bez zmian.
- `build.sh` przestaje podpisywać build entitlementem sandboxa, bo sandbox blokuje `sudo` i `osascript`. W buildzie z sandboxem (Xcode) przełącznik jest ukryty.
- Opcja domyślnie wyłączona. Instalacja helpera następuje dopiero, gdy użytkownik pierwszy raz włączy przełącznik.
- Bez daemona, bez `SMAppService.daemon` i bez XPC: przy podpisie ad-hoc, bez Team ID, to się nie sprawdzi.
- Nazwa pliku sudoers: `keepawake`. Plików z kropką w nazwie `sudo` nie wczytuje.

## Global Constraints

- macOS 14+, Swift 6.0, universal (arm64 + x86_64) przez `./build.sh --universal`.
- Wersja: `MARKETING_VERSION: 1.1.0`, `CURRENT_PROJECT_VERSION: 2` w `project.yml`.
- Reguła sudoers dokładnie: `<user> ALL=(root) NOPASSWD: /usr/bin/pmset -a disablesleep 1, /usr/bin/pmset -a disablesleep 0`.
- Każde wywołanie roota idzie przez `/usr/bin/sudo -n` (bez promptu, bez TTY) z pełnymi ścieżkami binarek.
- Plik sudoers: `/etc/sudoers.d/keepawake`, `0440 root:wheel`, przed instalacją sprawdzony przez `visudo -cf`.
- Copy w UI po angielsku (jak reszta aplikacji).
- Aplikacja nigdy nie rusza `SleepDisabled`, którego sama nie ustawiła (flaga `lidOverrideOwned`).

## Wymagania wstępne (przed Task 1)

- `sudo xcodebuild -license accept`: bez tego `swift` i `git` kończą się błędem licencji Xcode.
- Zacommitować obecne zmiany w `build.sh` i `release.sh` (już są w working tree), żeby v1.1.0 startowało z czystego stanu.

## Review Focus

1. **Aplikacja pada lub zostaje zabita (Force Quit, `kill -9`) przy aktywnym override:** strażnik w ciągu ~5 s robi `disablesleep 0`, a przy zamkniętej klapie usypia Maca. Test w Task 1 (`watchdogScriptResetsAndSleeps`) plus ręczny test w Task 5.
2. **Koniec czasu albo limit baterii przy zamkniętej klapie (laptop w torbie):** po `disablesleep 0` aplikacja woła `pmset sleepnow`, ale tylko gdy `AppleClamshellCausesSleep`. Test w Task 1 (`disableSleepsWhenLidClosed`).
3. **Użytkownik anuluje okno hasła admina:** przełącznik zostaje wyłączony, pojawia się komunikat, keepAwake działa dalej. Test w Task 3 (`installCancelledKeepsToggleOff`).
4. **Ktoś usunął `/etc/sudoers.d/keepawake` albo `sudo -n` odmawia:** keepAwake startuje ze zwykłym assertion i pokazuje komunikat; start nie jest przerywany. Test w Task 3 (`startWithoutHelperStillActivates`).
5. **Ponowne uruchomienie po crashu lub restarcie z pozostawionym `SleepDisabled 1`:** `init` kontrolera cofa override tylko wtedy, gdy `lidOverrideOwned == true`. Ręcznie ustawionego przez użytkownika nie rusza. Testy w Task 3 (`launchRecoversOwnedOverride`, `launchIgnoresForeignOverride`).

**Interfaces:**
- Produces:
  ```swift
  struct CommandResult: Equatable, Sendable { var status: Int32; var output: String }
  protocol CommandRunner: Sendable {
      func run(_ path: String, _ arguments: [String]) -> CommandResult
      func launchDetached(_ path: String, _ arguments: [String]) -> Int32?   // pid
      func terminate(_ pid: Int32)
  }
  struct ProcessRunner: CommandRunner          // Foundation.Process; terminate = kill(pid, SIGTERM)
  enum Clamshell { static func closedAndCausesSleep() -> Bool }   // IOPMrootDomain: AppleClamshellState && AppleClamshellCausesSleep
  @MainActor final class LidSleepOverride {
      static let sudoersPath = "/etc/sudoers.d/keepawake"
      static let watchdogScript: String
      init(runner: CommandRunner = ProcessRunner(),
           fileExists: @escaping (String) -> Bool = { FileManager.default.fileExists(atPath: $0) },
           lidClosedCausesSleep: @escaping () -> Bool = Clamshell.closedAndCausesSleep,
           helperScriptPath: String? = Bundle.main.path(forResource: "lid-sleep-helper", ofType: "sh"),
           isSandboxed: Bool = ProcessInfo.processInfo.environment["APP_SANDBOX_CONTAINER_ID"] != nil,
           appPID: Int32 = getpid())
      var isAvailable: Bool { get }   // !isSandboxed && helperScriptPath != nil
      var isInstalled: Bool { get }   // fileExists(sudoersPath)
      func enable() -> Bool
      func disable()
      static func parseSleepDisabled(_ pmsetOutput: String) -> Bool
  }
  ```
  (Metodę `install()` dodaje Task 2.)

- [ ] **Krok 3: Zaimplementuj `LidSleepOverride.swift`**

  while /bin/kill -0 "$1" 2>/dev/null; do /bin/sleep 5; done
